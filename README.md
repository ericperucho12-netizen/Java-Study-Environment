# Java Study Environment

This repository contains a complete, professionally structured roadmap for mastering Core Java. It is designed to act as both a theoretical encyclopedia and an intensive practical training environment. 

The project contains over 210 exercises and is strictly organized into 18 sequential topics, covering everything from fundamental syntax to advanced topics like Concurrency, Streams, and HTTP APIs.

## Repository Architecture

The repository is divided into three main pillars:

### 1. TodoSobreJava (Theory Library)
A collection of 18 interactive theoretical guides. Instead of static text files, the theory is written directly inside executable `.java` files. Each file contains an extensive header block explaining the concepts (Data Structures, Threads, Memory Management) followed by clean, compilable code examples.

### 2. Ejercicios (Solutions Manual)
The core of the repository. Contains 210 fully solved and documented exercises. Each file is designed to be self-explanatory, featuring a `Conceptos` and `Enunciado` section that describes the problem statement and the specific keywords being tested.

### 3. Ejercicios_Sin_Resolver (Training Ground)
A 1:1 clone of the 210 exercises where all logic and implementations have been wiped clean. It retains only the package structure, imports, and problem statements. This allows for rigorous blind-practice, forcing the reconstruction of algorithms, helper classes, and logic from scratch.

## Covered Topics

The curriculum is structured sequentially:

1. Basic Syntax & Constants
2. Control Flow (Conditionals)
3. Loops
4. Arrays & Sorting Algorithms
5. Matrices
6. Methods & Functions
7. Object-Oriented Programming (OOP)
8. Strings & Memory Pool
9. Java Collections Framework (List, Set, Map)
10. Exceptions (Checked vs Unchecked)
11. Java Time API
12. File Handling (I/O & NIO)
13. Functional Programming (Streams & Lambdas)
14. Concurrency (Threads & Synchronization)
15. Graphical User Interfaces (Swing)
16. HTTP Connections & REST APIs (java.net.http)
17. Regular Expressions (Regex)
18. Generics

## Usage Guide

1. Read the theoretical guide for a specific topic in the `TodoSobreJava` directory.
2. Navigate to `Ejercicios_Sin_Resolver` and attempt to solve the problems for that topic in an empty class.
3. Compare your implementation with the optimal solution found in the `Ejercicios` directory.
